# AstroGate AI 生成图像

右键画布 → 添加节点 → 图像 → **AstroGate AI 生成图像**，或双击画布搜索 `AstroGate`。

将 [示例工作流](examples/astrogate-generate.json) 拖入画布，即可使用「文本提示词 → AstroGate → 预览 / 保存」。

- 提示词：直接填写，或将控件转换为输入并连接 STRING 文本节点。
- 参考图：可不连接；连接「加载图像」或其他 IMAGE 输出后自动使用图生图。连接后出现下一个参考图插口，最多 8 张（包括输入批次）。
- 模型：当前接口提供 `gpt-image-2`。
- 画幅：13 种比例，默认 16:9。
- 分辨率：`original` 保留接口原图；1K/2K/3K/4K 长边分别为 1024/2048/3072/3840。明确选定分辨率时，按网站规则请求尺寸并裁切缩放返回图以匹配该尺寸；不代表模型原生输出该分辨率。
- 质量：`low` / `medium` / `high`。
- 统一设定：描述需要延续的人物、服装、配饰、场景和画风，可将同一个文本节点连接到多个生成节点。
- 视角：自由、正面、背面、左侧、右侧、配饰细节。每个节点分别输出一张；左右指人物自身的左右。
- 重绘编号：默认 `0`，输入及编号不变时复用当前 ComfyUI 缓存；修改编号重新生成该节点及依赖它的后图。`-1` 每次重画。这是缓存控制，不是模型随机种子。
- 图像输出：标准 RGB IMAGE，可连接后一个 AstroGate 节点的参考图，或「预览图像」「保存图像」、放大等处理节点。

执行时节点会显示「正在生成图像，请稍候…」，任务完成、失败或取消后提示会结束。接口没有提供实时进度百分比，等待时间取决于服务端。

生成图现在也显示在节点内部，使用「提示词展开/收起」只折叠文字；图片、文字和连线仍属于同一个节点。旧 `AstroGateImage` 的输入顺序与 IMAGE 输出保持兼容，仍需输出节点触发执行；其内置预览是临时文件。

## TXT 小说分镜（原生节点画布）

重启 ComfyUI 并刷新页面。点击画布顶部 **导入 TXT → AI 分镜**，或右键选择同名菜单，会在当前画布创建并连接：

`导入 TXT 剧本 → AI 分镜脚本 → 共享素材 / 独立分镜图片`

1. 在 TXT 节点选择文件（UTF-8、GB18030、UTF-16），原文与章节列表保存在项目中。也可搜索 `AstroGateTXT`、`AstroGateStoryboard` 手动添加并连接。
2. 在 AI 节点选择章节、画风、拆镜要求和模型，点击 **分析并自动建立节点**。默认 `gpt-5.6-terra`，提交 `reasoning_effort=xhigh`；可选 `gpt-6-luna`。每块正文先提取素材，再生成镜头与提示词，保留原文位置及分析草稿。重写编号不变时复用成功分析；修改编号明确重新分析，旧节点不删除。
3. 完成后自动建立真正的 ComfyUI 节点及连线。人物身份、服装造型、场景、道具共享；一镜可连多个人物。IMAGE 线是真正的参考图输入，剧情线只读取前情，不触发前镜生成。只有明确指定上一帧参考时才连接前帧 IMAGE。
4. 每张图片的预览、提示词、参数、生成按钮在同一个原生节点内，整体拖动。点击 **提示词与生成参数** 独立折叠，图片和连线保留。默认 `high / 4K`，可改比例、分辨率和质量。4K 指请求与最终输出尺寸，不保证模型原生细节达到4K。
5. 点击卡片 **生成图像**、顶部 **生成选中图片** 或 AI 节点 **生成本章图片**。按当前 IMAGE 连线准备依赖并交给原生队列；生成前显示新图数量及复用数量，卡片显示转圈和状态。没有图像参考时走文生图。已有成功图直接从磁盘读取，不因缓存清空再次调用图片接口。
6. **重绘** 明确另开请求；普通生成复用未修改的成功结果。修改提示词、参数或参考连线后重新生成对应节点。图片参考下游会检测上游更改；纯剧情关联不强制重画。成功旧图保留在项目历史中。素材卡片可 **设为定稿素材**，后续章节复用。
7. **恢复 / 整理节点排版** 补充缺失节点并整理位置，保留现有节点的手动提示词与连线。使用 ComfyUI 原生保存、加载工作流；AI 节点的 **导出项目与图片** 包含原文、项目、任务、工作流和独立帧。

`AstroGateStoryboardFrame` 是 V3 输出节点，IMAGE 输出可继续连接原生预览、保存、放大或其他生成节点。剧情和所属脚本接口使用惰性元数据连线；只有未完成图像任务才请求参考 IMAGE 输入。已导入的原生 LoadImage 也可直接接入参考口。单独自由生图仍使用原有 `AstroGateImage`。

未知、超时和失败不会自动重发。分析节点显示原始错误，点击 **重试未完成分析** 从已保存的阶段继续；结果未知时按钮明确标为 **结果未知，重新提交**。成功后自动建立节点，不必重新导入 TXT。修改重写编号用于重新分析整章。图片 **停止** 只针对本批次；已发送的远端请求可能继续执行，返回成功图仍保存。文本 **停止分析** 只停止当前参数对应的分析，保留当前返回的草稿，不再发送下一阶段。

项目数据库及请求快照在 `user/__astrogate/`，素材副本在 `input/astrogate/`，原生输出在 `output/AstroGate/`。请一起备份。换机器继续执行还需恢复数据库和图片目录；ZIP 导出不是自动跨机器迁移工具。

文本凭据仅由后端 `ASTROGATE_TEXT_API_KEY` 读取，默认请求 `https://www.astrogate.sbs/v1/chat/completions`。图片使用独立凭据。没有修改 ComfyUI 核心推理或新增核心外网请求。`xhigh` 是请求参数，不表示可观测的内部推理过程。

文本分析使用流式接收，默认每次请求最多等待 15 分钟，可通过后端 `ASTROGATE_TEXT_TIMEOUT`（秒）调整。节点显示当前分析阶段和等待时间；断流或超时仍标记结果未知，不自动重复请求。AI 摘录不是逐字引文时保留段落定位，将引文置空；原始回答仍在任务草稿中。

画布左下角的 **分镜日志** 默认收起，展开可查看当前画布任务的阶段、接口响应、已接收字数与错误，并可定位节点、停止或复制日志。停止图片任务会停止同一队列批次内未完成的图片。每 3 秒更新，保留最近 120 条事件；日志不展示密钥或模型的内部推理。原生队列的 0% 不表示外部接口没有执行。

[短篇样例](examples/storyboard-demo.txt) 覆盖双人、画外提及、换装及跨场景。人物和细节一致性需要检查；自动生成的引用关系也可在画布调整。

## 前图生成后图与人物多视图

将 [人物连续视图工作流](examples/astrogate-character-views.json) 拖入画布，修改左侧「统一角色设定」，即可分别生成场景人物基准、正面、背面、左侧及配饰细节。每张图都有独立的保存节点，可继续连接后续处理。

后图的**参考图 1 始终连接同一张定稿基准图**，参考图 2 可连接上一张图作为补充。工作流示例已接好这两条路径，减少只逐张传递时积累的外观变化。场景续图时选择「自由」，在本次提示词中描述新动作、新镜头或需要修改的物件；未指定修改的人物设定继续保留。

只想修改后图时，保持前图的提示词、统一设定和重绘编号不变。改变共享设定会让引用它的节点重新生成。定稿后用「保存图像」保存，再通过「加载图像」接入参考图 1；缓存可能在重启或内存回收后失效，保存后加载能跨会话固定基准图。

参考图和设定能引导一致性，但模型仍可能改变小饰品、左右位置或不可见的背面细节，需检查生成结果。分辨率适配不增加模型原生细节。

## 密钥与启动

设置服务端环境变量 `ASTROGATE_IMG_API_KEY`，或将桥接密钥保存到 ComfyUI 根目录的 `.secrets/astrogate-img-api-key`。此文件已排除 Git；不要放进工作流、截图或源码。私钥仅用于 SSH 登录，接口使用独立的桥接密钥。

默认连接 `https://img.astrogate.sbs/internal/astrogate/v1`，普通启动方式不变。可以在服务进程中设置 `ASTROGATE_IMG_API_BASE` 指向受信任的网关地址；该地址会收到密钥，勿设置为第三方地址。

```powershell
.\custom_nodes\astrogate\start.ps1
```

本机已配置服务器 SSH 访问时，可用以下命令启动隧道及 ComfyUI（替换 SSH 配置别名）：

```powershell
.\custom_nodes\astrogate\start.ps1 -SshHost your-server-alias
```

隧道仅监听 `127.0.0.1:18189`，默认转发入口服务器的 `127.0.0.1:43922`（当前站点转发端口）。直接连接源站时使用 `-RemotePort 43921`。按 Ctrl+C 退出会同时关闭隧道。端口可通过 `-TunnelPort`、`-RemotePort`、`-Port` 修改。

仅执行节点时上传提示词和已连接的参考图。认证信息由后端读取，HTTP 重定向被禁止，返回图直接从 base64 解码。失败或超时不自动重试，避免重复生成；超时后服务端仍可能在执行。
